# IntelliQuiz

A full-stack quiz platform built using the MERN stack that allows teachers to create quizzes and students to attempt them with real-time feedback.

## 🚀 Live Demo

https://intelliquiz-sigma.vercel.app

---

## 📌 Overview

IntelliQuiz is a web-based platform designed to simplify the process of conducting quizzes and evaluating student performance. It was actively used in a college environment by 60+ students and received over 2000 visits, providing real-world usage and feedback.

---

## ✨ Features

* Create and manage quizzes
* Attempt quizzes with real-time interaction
* AI-assisted feedback for performance improvement
* Responsive and dynamic UI built using React
* Handles multiple concurrent quiz attempts
* Secure data handling and storage

---

## 🛠️ Tech Stack

**Frontend:** React (JavaScript, HTML, CSS)
**Backend:** Node.js, Express.js
**Database:** MongoDB (MongoDB Atlas)
**Deployment:** AWS, Vercel

---

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/intelliquiz.git
cd intelliquiz
```

### 2. Install dependencies

```bash
npm install
```

### 3. Setup environment variables

Create a `.env` file and add:

```env
MONGO_URI=your_mongodb_connection_string
PORT=5000
```

### 4. Run the application

```bash
npm start
```
